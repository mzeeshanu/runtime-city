# Runtime City: brand and roadmap

## Brand

- **Product:** Runtime City
- **Tagline:** Learn by breaking
- **Lesson format:** each concept is a *playroom* inside a *district*
- **Domains to buy (Cloudflare):** `runtimecity.com` (main), `runtimecity.dev` (protection, dev blog), optionally `codeplayroom.com`. All showed as unregistered on 2026-09-21; confirm in Cloudflare before buying.
- **Before buying:** trademark search (USPTO, EUIPO, local office) and claim `@runtimecity` on YouTube, TikTok, Instagram, X and LinkedIn.

## Districts

| District | Topics |
|---|---|
| Pattern Park | Dependency Injection, Factory, Strategy, Observer, Singleton |
| SOLID Quarter | The five SOLID principles |
| Memory Harbour | Stack and heap, references, garbage collection |
| Network Highway | DNS, TCP, HTTP, TLS: what happens when you type a URL |
| Database Vault | Indexes, joins, transactions, isolation levels |
| Concurrency Crossing | Threads, locks, deadlocks, async/await |
| Architecture Heights | Microservices, queues, load balancers, CQRS |

## Roadmap

Timelines assume 15–20 hours a week.

### Phase 0: Foundation (weeks 1–2)
- [ ] Buy domains, claim social handles
- [ ] Landing page with the DI playroom embedded and an email waitlist
- [ ] Cloudflare Pages deploy + Web Analytics

### Phase 1: Test the idea (weeks 3–8)
- [ ] Watch 10 students use the DI playroom unassisted
- [ ] Build Factory Method, Strategy and Observer playrooms
- [ ] Post a 30–60 s screen recording of each playroom
- [ ] **Goal: 500 waitlist signups** (below ~100, rethink the pitch)

### Phase 2: Lesson engine + paid launch (months 3–4)
- [ ] Extract reusable visual building blocks into a lesson engine
- [ ] Accounts, progress tracking, payments (Lemon Squeezy or Paddle)
- [ ] Pattern Park (~8) + SOLID Quarter (5) playrooms
- [ ] Pricing: free first playroom per district; $3.99/month or $19 three-month interview pass
- [ ] **Goal: first 50 paying users**

### Phase 3: Grow the student product (months 5–8)
- [ ] Memory Harbour, Network Highway, Database Vault
- [ ] Interview mode: timed question sets, spoken-answer practice
- [ ] Free SEO page per concept
- [ ] 3 short videos a week
- [ ] **Goal: $1–2k monthly revenue**

### Phase 4: Early-career developers and teams (months 9–12)
- [ ] System design, concurrency and architecture districts
- [ ] Pro tier and team licences
- [ ] 2–3 bootcamp or university pilots
- [ ] Shareable completion certificates
- [ ] **Goal: ~$5k monthly revenue**

### Year 2
- 3D explorable city map
- AI tutor inside playrooms (usage-capped)
- More languages (Python, Go), mobile app, outside authors
